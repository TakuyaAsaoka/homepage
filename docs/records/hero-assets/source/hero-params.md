**動きの規則**

| 項目 | 値 | 根拠 |
|---|---|---|
| 速度の揺らぎ | 基本速度の **±18%**、周期 41秒 ＋ 23秒 | ±25%以上だと加速・減速が露骨に見える。後退させない |
| 濃さの変化 | **画面内位置に連動** `0.25 + 0.75·sin(π·u)`（u=0〜1の一巡） | 時間の sin で変えると往復に見える。位置連動なら「現れて消える」になる |
| 上下の揺れ | **なし** | 往復に見えるため削除 |
| 伸び縮み | **なし** | 同上 |

## 素材の処理手順（確立済み・コード化済み）

1. 白背景で生成（明度250以上）
2. 明度→アルファ変換（`HI=250, LO=218`）＋ **アンマルチプライ**（白フチを防ぐ）
3. 外接矩形でトリミング
4. 霞のみ：左右18%・上下10%をsmoothstepでフェード（**端の切り口を消す**）
5. 霞のみ：行方向の投影で帯を自動分離
