## 2. 確定していること

**確定しているのは第1幕（ASCII松）だけ。** これ以外はすべて白紙。

### 表現の骨子

```
【第1幕】文字が散らばっている → 集まる → 松のASCIIアートになる     ← 必須
【転換】  ASCIIから「絵」へ                                        ← 白紙
【第2幕】絵の中で無限ループ                                        ← 白紙
```

| 要素 | 意味 |
|---|---|
| 文字が集まる | **エンジニアである**ことの表現。コードが積み上がって作品になる比喩 |
| 松 | 施主が個人的に好きなモチーフ |
| 絵になる | 素材（文字）が完成品（作品）になる物語 |

### 第1幕：ASCII松（完成・パラメータ確定）

プロシージャル生成。形状は正規化座標の純関数で**密度非依存**（＝縦構図もパラメータ変更だけで出せる）。

| 分類 | 値 |
|---|---|
| 密度 | 150×56 |
| 色 | 彩色ON・鮮やかさ100・くっきり100 |
| 濃淡 | コントラスト200・全体の濃さ150・樹皮121・苔8 |
| 幹 | 傾き50°・太さ100・長さ100・中腹の枝116・線の揺らぎ110 |
| 樹冠 | 大きさ109・もこもこ102・葉の詰まり100 |
| 根 | 張り出し110・太さ38・沈み込み100 |
| 小枝 | **本数0**（ASCIIでは認識しづらいため不採用） |

再現方法: `docs/records/hero-assets/source/ascii-export.js` を `node ascii-export.js 0`（右向き）/ `1`（左向き）で実行するとセルのJSONが出る。
出力済みの画像: `docs/records/hero-assets/final/ascii-pine-{left,right}.png`（1536×956・1818セル）

### 決まっている制約

| 項目 | 内容 |
|---|---|
| **ASCII松と絵の松は同じ木** | 別の木に変わると「もはや別物」になる。転換の説得力が崩れる |
| 第1幕は必須 | 「文字が集まる」が表現の核 |
| 第2幕は無限ループ | 絵の中で動き続ける |
| 動くもの | **霞は必須**（「目立たないが後ろで動くと**奥行き感**が出て、**作り込まれている印象**になる」）。散る葉も欲しい |
| 不採用 | 季節連動・鶴・月 |

### 技術的な前提

- **Astro v6 / 静的サイト / GitHub Pages / ランタイム依存ゼロ**（既存の設計思想）
- **GPU無効環境の訪問者が現実に存在する**（施主のChromeが `Canvas: Software only`。Safariでは60fps）
  → Canvasを本番ランタイムに載せる設計は、この環境で破綻する
- ASCIIの文字は `# % * + : ; , .` の**重さで濃淡を作っている**。名前やコードの文字をそのまま使うと階調が崩れる
  （※「最初は名前 `ASAOKA Takuya` やコード断片から始めたい」という案がある。実現するなら「散らばっている間は名前/コード → 集まる途中で松の文字に変化」という構成になる）

## 3. 白紙の論点（次セッションの本題）

**施主の言葉:**
> 絵を作り直す、というのは、アスキーアートから日本画のような絵にどのようにつながるかが想像できないから決められないということです。
> まっさらな状態で作った方がより作りやすく、別アイデアも生まれると思っているからです。

つまり **「転換をどう作るか」が決まらないと「第2幕が何であるか」も決められない**。順序はこう:

```
転換の方法を決める  →  それが成立する第2幕を決める  →  素材を作る
```

**逆順（先に絵を作って、そこにASCIIを寄せる）で進めて失敗した。** 繰り返さないこと。

### 考えるべきこと

1. **ASCIIから何にどうつながるのか** — 日本画である必要すらない。ゼロベースで考える
2. その転換が**実装可能か**（GPU無効環境・ランタイム依存ゼロの制約下で）
3. 第2幕で**何が動くか**（霞は必須）

## 4. これまでに分かったこと（前提ではなく、失敗の記録）

> ここに書いてあるものは**採用済みではない**。同じ轍を踏まないための記録。

### 却下された案と、その原因

| 案 | 結果 | 原因 |
|---|---|---|
| 絵もプログラムで描く | ❌ 3回作り込んで「子供の落書き」 | 形状関数の情報量が絵の上限になる。日本画の質は数式で再現できない |
| AI生成の部品を合成 | ❌ 調和しない | 素材ごとに空気感が一体で描かれ、切り出すと矩形の名残が出る |
| 1枚絵＋Canvasで霞を重ねる | ❌ 「動きが不自然・画質が低い」 | 絵が静止したまま重ねた要素だけ動くのでレイヤーが分離して見える |
| 1枚絵をAIで動画化 | △ 動きの質は合格。**だが絵がASCII松と別の木**だった | 「絵を先に作った」ことが根本原因 |

### 却下した技術

| 技術 | 却下理由 |
|---|---|
| Three.js / PixiJS | セル数が数千規模でWebGLの損益分岐点（数万）に届かない |
| GSAP | 各セルは共有進捗tの純関数で書けるためトゥイーンエンジン不要 |
| シェーダー | 疎密度では1文字が大きく、ピクセル単位のにじみは文字の輪郭を溶かして主題を弱める |
| 深度マップ＋パララックス | 「カメラが動く」演出であって「絵の中身が生きる」演出ではない。WebGL必須 |
| AI自動レイヤー分離（SAM） | 物体の境界で切るだけ。空気感が要素をまたぐ問題は解決しない |
| DOM/CSS transform 合成 | GPU無効環境でCanvasと同等に遅い（実測）。レイヤー数が増えると逆効果 |

### 動画生成サービスの調査結果（規約確認済み・2026-08時点）

| サービス | 判定 |
|---|---|
| **Seedance 2.0**（WaveSpeedAI経由） | スタイル維持がGen-4.5より優れる。モーション安定性76.0 vs 43.0。**first/last frame指定でループが作れる**。480p 5秒 $0.60 / 1080p $3.00 |
| Runway Gen-4.5 | 権利は最もクリーン。だが**Gen-3廃止でキーフレーム制御ができない**（ループ不可）。無料プランでは動画生成不可 |
| Luma Dream Machine | Loop機能・16キーフレーム。**無料枠なし**（Plus $29.99/月）。解約後もデータが消える可能性あり、要ダウンロード保管 |
| Kling | **✕ 「Kling AIによって生成された」の表示義務**、学習・広告への無償ライセンス、中国法域 |
| ChatGPT（Sora） | **✕ 2026年4月にChatGPT内の動画生成が終了** |

**現状 WaveSpeedAI のクレジットが尽きている。** 生成を再開するには入金が必要。

### 動画化の実測値（Seedance 2.0 / 480p・5秒 / $0.60 / 1本のみ）

対象は `final/scene-full.png`（**ASCII松とは別の木**の絵）。結果は `final/loop-test-480p.mp4`。

| 項目 | 結果 |
|---|---|
| 日本画のタッチ維持 | ✅ 完全（写実化しない） |
| 松・灯篭・岩の形 | ✅ 崩れなし |
| カメラ固定 | ✅ 完全（ピクセル差分で左半分が完全に静止） |
| ループ（開始＝終了） | ✅ 実用レベル（平均差2%） |
| **霞の動き** | **❌ 動かない**（松の1/11の変化量。実質静止） |
| 音声 | 混入した。次回は `generate_audio` をOFFにする |
| 解像度 | 480pではヒーロー全幅に足りない（実測確認済み） |

**この検証で言えるのは「AIは日本画のタッチを保ったまま動かせる」ことだけ。** 絵そのものは採用が決まっていない。

### 素材処理の手順（コード化済み・再利用可）

1. 白背景で生成（明度250以上）
2. 明度→アルファ変換＋**アンマルチプライ**（白フチ防止）
3. 外接矩形でトリミング
4. 霞は端フェード＋帯の自動分離

### 実装時に効く知見（第2幕の形式が決まってから使う）

- フォールバックは2段:「`prefers-reduced-motion` → 静止画」「第1幕を計測窓にして**ロングフレーム率**（33ms超の割合）で判定 → 不合格なら静止画」。平均fpsはGCスパイクに鈍感なので指標にしない
- 切替は**転換点で1回だけ・単方向**（再生中の動的切替はちらつく）
- **静止画は1枚で3役**（reduced-motion / 低性能 / JS無効の `<noscript>`）
- `IntersectionObserver` でヒーローが画面外に出たら停止。タブ復帰時はdeltaをクランプ
- 高さは `svh`（モバイルのアドレスバー伸縮で再レイアウトしない）
- 素材は `src/assets/hero/` に置きESM import（ハッシュ付きファイル名・`base`解決）。**合計300KB以下を目標**
- `will-change` の乱用でレイヤー爆発 → fps低下を実測。使わない
